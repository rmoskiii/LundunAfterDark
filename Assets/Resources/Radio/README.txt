LUNDUN AFTER DARK · RADIO CONTENT (G8.2a)

Drop licensed MP3 files (WAV is fine for short idents and dispatch pieces) into these folders. Import settings are applied
automatically and the manifest (RadioManifest.txt) is regenerated by the Editor. Never edit RadioManifest.txt by hand.

STATIONS
  Southside/Tracks, Southside/Idents          SOUTHSIDE 2-STEP 94.7 (UK garage)
  Blockwork/Tracks, Blockwork/Idents          BLOCKWORK FM 101.3 (drill-inspired instrumentals)
  LundunTalk/Host                             LUNDUN TALK 1152 AM host segments (30-60 s)
  LundunTalk/News                             news templates TPL_CHASE_*, TPL_CRASH_*, TPL_WASTED_*, TPL_BUSTED_* and sign-offs SIGN_*
  LundunTalk/Places                           district and road names, file named after the place (e.g. Peckam.mp3, Rye_Lane.mp3)
  LundunTalk/Beds, LundunTalk/Idents          the bed and idents that fill news slots

LIVE POLICE FEED (one dispatcher voice)
  Feed/Openers      "Control to all units", "All units", "Any unit in the area"
  Feed/City         city bodies ("reports of disorder") - fictional activity only
  Feed/Places       fictional places for city dispatches, file named after the place
  Feed/Pursuit      OPEN_* (opening lines) and UPDATE_* (update lines)
  Feed/Districts    the district names in the dispatcher's voice, file named after the district
  Feed/Escalation   ARMED_* (armed response) and AIR_* (air support)
  Feed/StandDown    stand-down lines ("All units, stand down, resume patrol")
  Feed/Closers      "...over", "...received"

NAMING AND RIGHTS
  LIB_ prefix = a library track. It plays with RADIO ON once its licence is in place, never in STREAMER-SAFE.
  StreamerSafe.txt = the approved list for STREAMER-SAFE: exact paths like Radio/Southside/Tracks/night_bus_home
  (case-sensitive, no extension). Add a file only when its contract covers streams and player clips.
  Never name files PLACEHOLDER_ or TEST_, or put them in Placeholder or Test folders: release builds stop if you do.
  Every file needs worldwide, perpetual rights for distribution in the game, marketing, player clips and streaming.

Until real content exists, the Editor and development builds play code-made placeholders (labelled PLACEHOLDER).
Release builds never contain placeholders: a station with no tracks is hidden; missing pieces are simply left out.
